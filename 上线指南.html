2. 最快路径：5 分钟先把现有 HTML 装进手机

你的动作手册手机版和30 节训练计划HTML 文件已经能用了。最快的"它在我手机上能用"路径——直接加到主屏：

1把 HTML 上传到一个能从手机访问的地方

最简方式：GitHub Pages

  1. 注册 GitHub 账号（如果还没有）
  2. 新建一个 repo，名字比如 fitlab
  3. 把 健身/ 文件夹里的所有文件拖进 repo（直接在网页上拖）
  4. Settings → Pages → Source 选 main 分支 → 保存
  5. 等 1-2 分钟，你会得到一个 URL：https://你的用户名.github.io/fitlab/

2手机打开这个 URL → 加到主屏

手机操作
iOS Safari 打开 → 底部"分享"按钮 → 滚到"添加到主屏幕" → 改个名字"FitLab" → 添加
Android Chrome 打开 → 右上角菜单 → "添加到主屏幕" / "安装应用"
完成后桌面会出现一个图标。点开它会全屏打开，看起来跟原生 App 一样。所有数据存在浏览器 localStorage，关闭也不丢。

这个最快路径 5 分钟可完成。但目前打开的还是 5 个独立 HTML（手册/计划/分析等），没整合成 3 tab。

2托管（hosting）· 把代码放到一个能从手机访问的地方

详见第 4 节托管对比。最简：GitHub Pages（免费）。

3装到手机

同第 2 节"加到主屏"。第一次安装后，以后改代码 push 到 GitHub，手机里的 App 自动更新。

4持续迭代

本地写代码 → git push → 等 1-2 分钟 GitHub Pages 自动部署 → 手机里的 App 下次打开就是新版。

# 1-2 分钟后，访问 fitlab.github.io 已经是新版

6. 进阶选项（不急）

原生 App Store 上架

如果未来想让其他人能搜到下载：

  • iOS App Store：需要 Apple Developer 账号 $99/年。审核 1-2 周。需要原生或 Capacitor 包装的版本
  • Android Play Store：开发者账号一次性 $25。审核快。可以直接传 PWA 的 .twa 包

建议：先 PWA 跑半年，验证产品价值后再考虑商店。

多设备同步

目前所有数据存在浏览器 localStorage，换手机数据丢失。如果要同步：

方式实现
手动备份/恢复
（推荐先用这个）		设置页加"导出 JSON"和"导入 JSON"按钮。$0 成本
GitHub Gist 同步用户给个 token，把数据存到自己的 Gist。$0 成本但稍复杂
自建后端需要服务器（如 Vercel Edge Functions / Supabase 免费层）。$0-10/月
iCloud / Google Drive 同步PWA 限制，做不到

推送通知

"该训练了"这种提醒。PWA 在 Android 上支持原生，iOS 16.4+ 也支持但有限制。需要：

  • Service Worker 注册 push subscription
  • 一个能发推送的服务（Firebase Cloud Messaging 免费）
  • 用户首次访问时引导同意通知权限

Phase C 再考虑。

自定义域名

不想用 username.github.io/fitlab，想用 fitlab.com：

  1. 从 Namecheap / Cloudflare / GoDaddy 买域名（$10-15/年）
  2. 设 DNS CNAME 指向 username.github.io
  3. GitHub Pages 设置里加 Custom domain
  4. 勾选 "Enforce HTTPS"

立即可执行的下一步
