📖 评判依据：MEV / MAV / MRV 是什么？阈值哪里来？怎么算"周等效组数"？

① 三个阈值的含义（生理学定义）

三个阈值来自 Mike Israetel 的 Renaissance Periodization · Scientific Principles of Hypertrophy Training（2018 出版）。他基于 Schoenfeld 等人的研究 + 多年训练数千运动员的实测数据，提出了"训练量响应曲线"：

阈值含义（生理学）实际意义
MV
Maintenance Volume		维持现有肌肉量所需的最少周组数低于此值肌肉会萎缩
MEV
Minimum Effective		开始触发肌肥大的最低组数低于此值 = 维持但不长
MAV
Max Adaptive		增长最快的"甜区"组数这是要瞄准的目标
MRV
Max Recoverable		身体能恢复的最大周组数超过此值 = 过度训练 / 减损

"1 组" 这里指 RIR 0–3 的有效组（接近力竭，留 0-3 次余量），不是热身组。

② 数字本身的科学溯源

  • Schoenfeld 2017 Meta-Analysis（10 项 RCT, J Sports Sci）：每周 1–4 组 → 5.4% 肌肥大；5–9 组 → 6.6%；10+ 组 → 9.8%。剂量-反应明确存在拐点。
  • Krieger 2010：< 5 组/周几乎无增长，→ 这就是MV/MEV 下沿的依据。
  • Israetel RP（2018）：基于 Schoenfeld 的曲线 + 实测训练员数据，给出每肌群独立的 MEV/MAV/MRV 三档（不是研究 RCT 的直接结果，是 RP 工程化的合理近似）。

③ 个体差异 — 数字不是"圣经"

这些阈值是 中级训练者的均值。真实你的位置会受以下因素影响：

  • 训练经验：新手只需 MEV 就能长；高级要靠近 MRV 才能继续推进
  • 性别：女性 MRV 通常比男性高 10–20%（恢复更快）
  • 睡眠 / 营养 / 压力：恢复差时整体 MRV 会下移
  • 个体遗传：肌纤维比例、激素水平等

→ 所以本看板的判断仅作为"客观参考"，最终调整还要看你自己的恢复体感、力量进度、肌肉感觉。

④ "周等效组数"怎么算？

不同时间窗口里组数的绝对值不能直接比，所以归一化到"如果按当前节奏，每周会有多少组"：

周等效组数 = 期内累计组数 × 7 / 期内天数

例如：
• 单次（1 天）做胸 4 组   → 4 × 7 / 1 = 28 组/周
  （意为：如果天天这么练，胸的周组数就是 28，已超 MRV）
• 1 月（30 天）做胸 16 组 → 16 × 7 / 30 ≈ 3.7 组/周
  （远低于 MEV 10）

这样所有粒度都映射到同一刻度，可与 MEV/MAV/MRV 直接比较。

📖 表头每一列什么意思？为什么单次/周/月显示的数值不一样？

命名约定：所有肌群用「父肌肉-子部位」格式。例：胸大肌-上部 是 胸大肌 的锁骨头，不是 胸小肌（胸小肌是胸大肌下面的小稳定肌，不参与本表训练评估）。手册里"胸大肌"会自动归到"胸大肌-上部 + 胸大肌-中下部"两个子部位。

每列含义和公式：

列含义公式
状态该肌群在当前粒度的训练强度评级周等效组数 vs MEV/MAV/MRV
周等效组数 ⭐归一化到"每周组数"，用于与 MEV/MAV/MRV（周量）直接比较期内有效组数 × 7 / 期内天数
周频次归一化到"每周训练该肌群几天"期内被刺激的不同日期 / 期内周数
期内总容量所选期内的累计容量（kg）Σ 主肌动作 容量×1.0 + 协同肌×0.5
最强动作 / 1RM期内击中该肌群、估算 1RM 最高的动作Epley: 重量 × (1 + 0.0333 × 次数)

同样的训练数据在不同粒度下"周等效组数"举例：

粒度计算含义
单次（1 天，做 4 组）4 × 7 / 1 = 28"如果每天都这样训练每周就 28 组"。单次比 MEV 意义有限（没人每天练同一块），建议看"期内总容量"。
周（7 天，本周 4 组）4 × 7 / 7 = 4当周实际组数，直接和 MEV/MAV/MRV 比较。最自然的粒度。
月（30 天，月内 16 组）16 × 7 / 30 ≈ 3.7"按这一个月的训练节奏，平均每周做 3.7 组"。
季度 / 全部同理 ×7/天数跨段的平均周组数。

状态评级（按当前训练目标的 MEV/MAV/MRV）：
  周等效 = 0 → ⚪ 未训练
  0 < 周等效 < MEV → 🔴 不足（不足以触发肌肉增长）
  MEV ≤ 周等效 < MAV → 🟡 下沿（有效但未达甜区）
  MAV ≤ 周等效 ≤ MRV → 🟢 甜区（增长效率最高）
  周等效 > MRV → 🟣 超额（超过恢复能力，反损肌力）
