③ 覆盖度评估 · 我们这 34 块够不够全？

先把"全身一共多少肌肉"这件事说清楚，再看我们当前监控的 34 块在健身相关的肌肉里占多大比例。

全身骨骼肌
~600–840 块
命名口径不同；常见说法 ~700
健身相关 / 可主动训练
~45–50 块
其余多为面部/咀嚼/足底内在/内脏等
本系统当前监控
34 块
覆盖约 70%，主要肌群基本齐

为什么"全身 700 块"和"健身相关 50 块"差这么多？因为人体里大部分肌肉不在健身训练范围内：面部表情肌、咀嚼肌、舌头、咽喉、眼外肌、足底内在肌、各种深层小稳定肌、内脏平滑肌、心肌——这些要么不可自主控制，要么没有针对性训练动作。健身真正"练得到、量得到"的，就是这 40 多块。

未覆盖但健身相关的肌肉清单

分三档：🔴 建议加（有专门动作能练、训练相关性高）；🟡 可选（功能跟已收录的肌肉重叠，常被代表）；⚪ 不必单列（不训练 / 已合并 / 非健身相关）。

优先肌肉区域功能 / 为什么重要典型训练动作
🔴前锯肌
Serratus anterior		背 / 肩胛肩胛前伸 + 上回旋。圆肩、翼状肩胛的关键肌；推举/倒立稳定的基础Push-up plus、哑铃直臂前推、负重熊爬
🔴大圆肌
Teres major		背肩内收 + 内旋。下拉/划船里参与度很高，常被并入背阔肌但实际工作量大引体、高位下拉、划船（已在做）
🔴腰方肌（QL）
Quadratus lumborum		腰 / 核心抗侧屈、骨盆稳定。单侧负重和侧桥的主练肌；下背痛的常见相关肌侧桥、农夫行走（单侧）、单侧哑铃下蹲
🔴肱肌
Brachialis		手臂纯粹的屈肘肌（不参与前臂旋转），藏在肱二头肌下面，体积可观锤式弯举、反握弯举、TRX 弯举
🔴肱桡肌
Brachioradialis		手臂前臂中立位时屈肘最强；锤式弯举主力之一锤式弯举、反握弯举
🔴胫骨后肌
Tibialis posterior		小腿（深层）踝跖屈 + 足内翻，维持足弓。跑者足弓塌陷常和它弱有关足内翻抗阻、单腿提踵 + 内翻
🔴胸小肌
Pectoralis minor		胸（深层）肩胛前倾 + 下回旋。过紧是圆肩的主因之一主要靠拉伸 / 松解管理，而不是练强
🔴颈部肌群
SCM + cervical extensors		颈颈屈 / 伸 / 旋。久坐人群的"乌龟颈"和它直接相关颈四向抗阻、靠墙颈拉伸
🟡多裂肌 Multifidus腰 / 核心深层脊柱稳定。鸟狗、死虫激活它，但和「竖脊肌」功能重叠鸟狗、死虫
🟡臀小肌 Gluteus minimus臀髋外展、稳定，功能跟臀中肌几乎一样蚌式、侧抬腿（同臀中肌）
🟡股二头肌-短头 Biceps femoris short head大腿后只屈膝（不跨髋），坐姿腿弯举侧重它坐姿腿弯举
🟡缝匠肌 Sartorius大腿前 / 髋屈髋+屈膝+外旋的细长肌，功能被髂腰肌+股直肌+内收肌覆盖侧弓步、单腿瑜伽姿势
🟡跖肌 Plantaris小腿小腿后侧的小肌，和腓肠肌一起，可有可无提踵附带
⚪肩袖 4 块（冈上 / 冈下 / 小圆 / 肩胛下）肩已被收录为「肩袖肌群」一个组——不展开面拉、外旋训练
⚪趾屈/伸肌、足底内在肌足非健身训练范围—
⚪肋间肌、深层颈小肌躯干 / 颈呼吸 / 姿态相关，不主动训练—
⚪面部肌、咀嚼肌、舌、咽喉头不在健身训练范围—
⚪内脏平滑肌、心肌—不可主动训练—
整体结论：34 块覆盖了 所有"练得到、量得到"的主要肌群——胸/背/肩/手臂/核心/下肢都齐了。真正应该补的是 🔴 那 8 块，尤其 前锯肌、大圆肌、腰方肌、肱肌、肱桡肌，加上它们之后系统就接近完整。
要把🔴那批加进训练系统吗？告诉我，我把它们写进训练数据库.js 的肌肉表（含 MEV/MAV/MRV）和相关动作的贡献系数（比如肱肌/肱桡肌要并入弯举类、前锯肌要并入推举类）。这是个数据库扩展+所有页面联动的活，不是改一处就行的。
